## 二、 两部参考视频在本项目中的核心定位

```
                    ┌────────────────────────────────────────────────────────┐
                    │               《大雨还在下十方神佛在怒骂》             │
                    │               【叙事本体 / 分镜骨架 / 情绪灵魂】       │
                    │  • 1986版齐天大圣桀骜狂气与反叛神权的故事线           │
                    │  • 唱词与音节重音基准（天兵合围 -> 横扫 -> 五指山）    │
                    └───────────────────────────┬────────────────────────────┘
                                                │ (内容蓝本)
                                                ▼
┌────────────────────────────────────────────────────────────────────────────────────────────┐
│                  当前 10 秒 MVP 视频（out/senbon_v8_mvp.mp4 / WukongClimaxSegment）        │
│                  【最终合成呈现：用现代代码动画与版画语言重塑经典神话】                    │
└───────────────────────────────────────────────▲────────────────────────────────────────────┘
                                                │ (技术规格与视听语言)
                    ┌───────────────────────────┴────────────────────────────┐
                    │               《千本樱 MV》（Opus 5.5 制作）            │
                    │               【工程管线 / 视听风格 / 排版与合成标杆】  │
                    │  • Remotion + Blender + ComfyUI 工业级三权分立管线     │
                    │  • 大正浪漫木刻版画风格（四色套版、半调网点、复古印章） │
                    │  • 高密度微切镜、动能文字排版、物理遮罩转场与卡点节奏  │
                    └────────────────────────────────────────────────────────┘
```

1. **《大雨还在下十方神佛在怒骂》（拍什么）**：
   * 提供了全片最核心的**剧情张力**与**音频源头**。
   * 10 秒 MVP 聚焦于该视频 09–19 秒的高潮冲突：从天庭天兵合围、金箍棒横扫千军、再到被佛祖翻掌压于五指山下、最后以大圣怒视天地的坚毅眼神收尾。
   * 本项目的歌词对齐文件（`public/alignment/climax_words.json`）与真实音轨（`public/audio/climax_real_vocal.wav`）均精准取自此片段。

2. **《千本樱 MV》（怎么拍）**：
   * 提供了全片的**视听语言范式**与**工程落地规格**。
   * 摒弃低幼或劣质的 Flash/PPT 质感，全面吸纳千本樱 MV 经受住检验的视觉法则：
     - **木刻套版色彩系统**：以玄黑、宣纸白、朱砂红、鎏金黄为主色调；
     - **五层复合图元**：战幡、符咒、铁索、实心印章必须具有双层描边、角花与暗纹；
     - **物理遮罩与微切镜**：利用障子门、刀光裂屏、黑山撞幕等物理边界切镜，每 0.6–1.2 秒一刀；
     - **多工具协同管线**：证明了“Remotion 负责时间轴排版合成 + Blender 负责 3D 物理与场景 + 图像模型负责角色形体”的高上限工作流。

## 四、 使用与引用指引

1. **音频提取**：
   若需重新校验真实唱段，请使用项目自带的 Remotion ffmpeg 从 `大雨还在下…mp4` 提取：
   ```powershell
   $ff = (Resolve-Path "node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe").Path
   & $ff -y -ss 9.0 -t 10.2 -i "references/大雨还在下十方神佛在怒骂_哔哩哔哩_bilibili.mp4" -vn -acodec pcm_s16le -ar 48000 -ac 2 "public/audio/climax_real_vocal.wav"
   ```

2. **抽帧比对与自检**：
   在任何新的分镜迭代后，建议使用 `scripts/contact_sheet.py` 同时抽取 MVP 成片与两部参考片对应区间的接触表，进行多模态视觉对齐校验。
