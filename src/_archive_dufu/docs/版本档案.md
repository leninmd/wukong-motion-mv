# 版本档案（V1 / V2 / V3）

三个版本的工程代码都在同一个仓库里，用分支隔离；**视频文件分两处存放**：

- **仓库内**：720p 预览 + 1080p 压缩版（每个 <50MB，`git clone` 后可直接播放）
- **Releases 附件**：1080p 广播级母版（每个 86–357MB，超过 GitHub 单文件 100MB 限制，故不作为 git 对象提交）

| 版本 | 分支 | 时长/帧率 | 声音 | 文字来源 | 仓库内 | Release 母版 |
|---|---|---|---|---|---|---|
| **V1** 诗史 | `main` | 85s / 30fps / 2550 帧 | 男声旁白 + 配乐 + 音效 | 现代文案（含部分杜撰） | `output/preview_720p.mp4`、`output/v1_release_share.mp4` | `dufu_v1.mp4`（86MB） |
| **V2** 少陵野老 | `feat/v2-masterpiece` | 85s / 60fps / 5100 帧 | 男声旁白 + 配乐 + 音效 | 现代文案（立意已改，仍有现代句） | `output/v2_release/dufu_v2_preview_720p.mp4`、`dufu_v2_share_1080p.mp4` | `dufu_v2_masterpiece.mp4`（250MB） |
| **V3** 万古诗史 | `feat/v3-120s` | 120s / 60fps / 7200 帧 | **零旁白**，纯环境与打击点 | **只用原典**（两唐书/元稹/韩愈/杜甫七诗） | `output/v3_release/dufu_v3_preview_720p.mp4`、`dufu_v3_share_1080p.mp4` | `dufu_v3_silent_master.mp4`（357MB） |

## 三版的核心差异（一句话）

- **V1**：把抖音苏轼短片的叙事骨架移植到杜甫身上，证明"代码逐帧渲染"这条路能走通。
- **V2**：修正立意（去掉"内耗废物"的苏轼母题，改成杜甫的具身苦难），挂载六个开源美学库，帧率翻倍。
- **V3**：删掉旁白，把"准绳"提到第一位——屏幕上每个字都能在两唐书、元稹墓志、韩愈诗与杜甫原诗里逐字找到；渲染管线扩到八层。

## 每版怎么重建

```powershell
# V1（main）
git checkout main
python tools/fetch_fonts.py
python audio/build_audio.py
python render/render3.py frames --out output/frames --fps 30
powershell -ExecutionPolicy Bypass -File .\run_all.ps1

# V2（feat/v2-masterpiece）
git checkout feat/v2-masterpiece
python audio/build_audio.py
python render/render3.py frames --out output/v2_work/frames60 --fps 60
powershell -ExecutionPolicy Bypass -File .\encode_v2.ps1

# V3（feat/v3-120s）
git checkout feat/v3-120s
python audio/build_audio_v3.py
python render/render3.py frames --out output/v3_work/frames --fps 60
powershell -ExecutionPolicy Bypass -File .\encode_v3.ps1
```

> 注意：`storyboard.json` 与 `storyboard.v3.json` 是两代剧本；V3 分支的 `app.js` 默认读 `storyboard.v3.json`。
> 渲染器 `render/render3.py` 支持 `V2_RENDER_PORT` 环境变量，可多进程并行出图。
