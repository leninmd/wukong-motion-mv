## 一、立意重构：从「内耗废物」到「悲悯破防」

| | V1 | V2 |
|---|---|---|
| 黑屏段母题 | 照搬苏轼版：「无法改变环境／无法改变自己／每天都很焦虑／自己是个废物」 | 杜甫的具身苦难：`廿四岁·壮游齐赵`、`困守长安十年`、`幼子饿死同谷`、`茅屋为秋风所破` 作为刚体字块砸落堆成废墟 |
| 叩问逻辑 | 「你会怎么办？」（空洞的自我怀疑） | 「十年求职无门，连家人的屋顶都护不住。」→「当苦难把你逼成世人眼中的废物」→「**你还肯为这个人间，流一滴眼泪吗？**」 |
| 收束 | 「杜甫把一手烂牌，打成了诗史。」 | 「杜甫把**最苦**的一手烂牌，熬成了大唐的诗史。」（熬，不是打——他没有赢过） |
| 旁白 | 9 句，其中黑屏段 1 句 | 11 句，黑屏段 3 句递进（灰尘→具身苦难→流泪之问） |

**核心判断**：苏轼解决的是"我如何与倒霉的自己和解"，杜甫解决的是"时代碾碎我全部理想、连屋顶和幼子都护不住时，我仍然为苍生立传"。
前者是**自救**，后者是**慈悲**。V1 把后者写成了前者的翻版，这是最致命的问题；V2 把"废物"改回**世人评说**（画面旁注：`—— 世人如此评说`），
让这个词从"自我否定"变回"被时代误读"，整段的情绪落点从"内耗"翻转成"心疼"。

## 五、音画与工程数据

- 画幅/帧率：**1920×1080 / 60fps / 5,100 帧 / 85.00s**（V1 是 30fps / 2,550 帧）
- 渲染管线：Canvas 逐帧 JPEG（q96）落盘 → ffmpeg libx264；**全片渲染 1,149 秒（19.2 分钟）**
- 母版：`crf 16 / preset slow`，24,681 kb/s，250.1 MB（超 GitHub 单文件限制，仅本地保留）
- 分享版：720p / 13.7 MB，入库
- 质检：`node engine/qa-gate.mjs` → **13/13 通过**；成片文件抽检无死帧/冻结帧/音轨缺失
- 亮度曲线（5s 采样）：201→185→71→29→30→192→197→147→23→24→196→13→14→15→205→193→191
  —— 明暗交替与九个章节完全对应，片头第 0 秒即 201（宣纸），无黑屏
- 旁白：edge-tts `zh-CN-YunjianNeural`，11 句，全部落在各自章节内且相邻间隔 ≥0.14s（末句 84.94s 收）
- 音效卡点：朱印 ×4、秋风/竹叶、红线低频下坠、刚体砸地 ×9、翻牌 ×4、落款重击，全部提前 2–3 帧触发
- 混音：旁白归一后 sidechain ducking（-6dB），母带峰值 0.93 不削波

## 六、尚存不足与下一版

1. **刚体废墟是 AABB 近似**：字块之间仍有轻微互穿，`PrebakedCollapse` 没有真实的多边形旋转碰撞
   （上 Matter.js 的多边形碰撞可解，但要接受多一个依赖）。
2. **点云质感**仍是"墨点山"，与参考片的 Three.js 真点云有差距；下一版可上体积雾与轮廓重采样。
3. S03 的竹叶偏"剪影"，近景缺叶脉细节；S06 的沙鸥在极小尺寸下仍略抽象。
4. 黑屏段 9 秒（00:55–01:04）在抖音可能掉点，发布时用剪辑版压到 6 秒更稳。
5. 现版本 16:9 横屏；9:16 竖屏需要重排 HUD 与竖排诗行（工作量约 40%，不急）。
