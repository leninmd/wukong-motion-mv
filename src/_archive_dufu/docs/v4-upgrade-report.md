# V4 手术记录：从「电子碑林默读测试」到「一镜到底的笔墨长卷」

> 本文记录 V3 → V4 的**减法手术**。V3 通过了 17 项工程探针，却"看不下去"。
> V4 不是再加特效，而是把出戏的东西一件一件拆掉，再把中国画的语言一件一件装回去。

---

## 1. 病灶一：120 秒零旁白 → 88 秒 + 真实乐器

### 做了什么

1. **总时长 120s → 88s**。九个分镜的"静帧 Hold"尾段全部剪掉，只保留视觉有信息的部分。
   章节之间的重叠从 0.2s 扩到 **1.2s**：不是变长，而是把"等待"换成了"交叠运动"。
2. **audio/build_audio_v4.py** 重写音轨引擎：
   - **Karplus-Strong 拨弦物理建模**（分数延迟 + 一阶低通环路），三种奏法：
     - san 散音：低音长鸣，循环滤波系数低 → 木胎共鸣；
     - fan 泛音：频域只留偶次谐波 → 清亮的"指尖离弦"；
     - yin 吟猱：延迟长度做 5.6Hz 正弦调制 → 音高游移（按弦揉动）。
   - **堂鼓**：指数频率下潜 f = f0·exp(−t·15) + 皮膜噪声瞬态 + 非谐泛音体鸣。
   - **音画同步**：同步表直接读 storyboard.v4.json 的 cues 与 sfx，
     与画面共用同一张表 —— 每一个词组落字、每一次朱印、每一块断碑坠地，音轨上都有对应。
3. **两段硬静默**（V3 唯一值得保留的声音设计）补上了前后：
   33.30–34.55（广厦成形）与 59.30–60.85（数尝寇乱）之前，
   战鼓连击从 2.2Hz 推到 7.5Hz + 风雨渐强 + 反向吸气噪波；
   一刀切下去才是静默，静默之后的一记洪钟 / 孤琴泛音才击穿。

## 2. 病灶二：理工科视觉 → 毛笔、界画、碑拓、皴法

新增 engine/v4/inkbrush.js（笔墨工具箱）与 engine/v4/cadence.js（句读律动）。

### 2.1 点云群山 → 皴法层峦（engine/world3d.js）

- **3D 投影坐标计算全部保留**，但废除了"画散点 fillRect"。
- 新渲染：沿脊线取 96~132 列，每列从脊线向下打干笔皴擦（三档墨色 55%/34%/18%），
  长度与密度随深度衰减，最终自然透明 —— **山无脚**。
- 分镜里的实心山体（_mass）同时改成垂直渐变（脊线焦墨 → 山脚 0），
  两者叠加才出现宋画那种"山从纸里长出来"的体积。

### 2.2 广厦晶格 → 水墨界画（engine/v3/celestial-lattice.js）

- 黄金角排布 + 透视 + 生长动画原样保留，**渲染方式整体替换**。
- 每一座殿宇 = 实心墨形（台基 / 柱 / 反宇飞檐 / 鸱吻 / 斗拱）+ 三笔毛笔勾边 + 一点朱砂灯火。
- 越远越淡（大气透视与"山无脚"同一套逻辑）：shade = lerp(52, 22, depthFade)。
- 每座殿宇背后垫一层极淡的暖光 —— 否则纯黑剪影会沉进纯黑夜底，
  "安得广厦千万间"就变成了"安得一片黑"。

### 2.3 多边形断碑 → 金石碑拓（engine/v3/fine-poly-ruins.js）

- 碑体：#161614 扑墨黑 + 垂直渐变。
- 边缘：沿多边形周界高频抖动凿出**石花崩茬白边**。
- 碑文：**阴刻白文**（先画 1.5px 偏移的黑色字口阴影，再压白文），
  并按概率在字口周围撒崩茬碎点。
- 崩裂：不再是规则多边形碎片，而是带**飞白尾迹**的石屑与墨块。

### 2.4 火柴人 → 减笔人物（engine/figures.js）

DFS.figure 改为 3~5 道墨迹立骨：
① 宽袍主干（一道飞白大笔，随风吹出弧度）② 斗笠（一道扁弧）
③ 迎风扬起的外袖 ④ 贴体内袖 ⑤ 竹杖。
wind 越大，下摆与袖口飘得越开。

### 2.5 数码 HUD → 朱丝栏边栏（engine/hud.js）

- **删除**四角 HUD：编号 / 进度条 / 坐标 / km 等宽数字全部移除。
- **左侧朱丝栏**：双线界栏（x=76 / x=128，y=118…962），栏内竖排 地点 / 纪年 / 里程；
  里程改成汉字记数「行三一二〇里」，颜色淡墨与暗朱砂，栏线带轻微抖动与断续。
- **右侧双行小字夹注**：竖排考据出处（《旧唐书·杜甫传》等），
  在章节后段才浮现，像拓工补写题跋。

## 3. 病灶三：八层过载 → 五层 + 预算制

engine/v3/eight-layer.js 重写为**预算制管线**：

| 层 | V3 | V4 |
|---|---|---|
| L3 体积光 | 常开，lighter 全屏 | **×0.30**，光柱透明度再 ×0.55 |
| L6 气溶胶 | 160 粒，画在排版**之后** | **48 粒 ×0.28**，移到排版**之前**（永远不会盖字） |
| L6 调色 ash | saturation 全屏降饱和 | 改为 ×0.14 冷灰 multiply（保住暗部与纸白） |
| L8 颗粒 | 0.45，两张 tile 叠化 | **×0.42**，淡颗粒只铺一张 |
| L8 暗角 | 0.26 | **×0.62** |
| 云雾 | 22 层 | 层数 ×0.55、透明度 ×0.62 |

另外给每一处 V3.inkText 加了**局部消光护罩**（V4.halo）：
亮字垫暗、暗字垫亮，只作用于文字包围盒的椭圆，绝不整屏压暗。
这才让"文字压在广厦 / 断碑 / 水纹上依然可读"。

## 4. 病灶四：机械入场 + 分镜孤岛 → 句读律动 + 一镜到底

### 4.1 三种入场物理模型（engine/v4/cadence.js）

| mode | 用于 | 物理 |
|---|---|---|
| hist 史笔刀刻 | 《两唐书》纪事 | 4~6 帧 outQuint 极速落位，**无模糊**，刀刻抖动，句读硬停 0.14–0.24s |
| chant 杜诗吟诵 | 杜甫原诗 | 0.42s 缓落 + 墨晕外扩；按 二·二·一 / 二·二·三 句读分组，组间停顿 0.35–0.45s；句末重字放大 **1.35×** |
| rub 墓志碑拓 | 元稹墓志 / 韩愈诗 | 0.75s 由淡及浓"洇"出来，密度爬升 + 轻微放大 |

storyboard.v4.json 的 cues 是唯一事实来源：

    { "id": "s04_a", "t": 8.05, "mode": "chant", "charDur": 0.13, "pause": 0.42,
      "emph": ["间"], "groups": ["安得", "广厦", "千万间"] }

- groups 必须以**句读**切分，拼接后必须等于原文（qa_probe_v4 会校验）。
- emph 是句末重字，渲染时放大 1.35×。
- 同一个调度器（JS 的 V4.schedule ↔ Python 的 schedule）同时驱动画面与音轨 —— 这就是毫秒级同步的来源。

### 4.2 一镜到底：交叠窗口 + 镜头承接（app.js）

- 相邻分镜重叠 **1.2s**；但只有正中 **0.36s** 做真正的交叉溶解，
  其余时间交给运动 —— 既不断崖，也不"糊成灰"。
- 出场镜头：Whip Pan（横向 0.9 屏宽，p^2.4）或 Zoom-through（1 → 2.05×，绕焦点）；
  入场镜头反向承接（从屏幕外滑入 / 从 1.95× 收拢到 1）。
- **贯穿全片的墨屑锚点**：16 颗确定性漂移的墨屑，不属于任何一个分镜，
  所以在任何一帧都能看见它 —— 这是"一镜到底"的物理证据。

## 5. 病灶五：17 项工程断言 → 22 项（含 5 道美学门控）

render/qa_probe_v4.py：

| # | 门控 | 判据 |
|---|---|---|
| T18 | **留白率硬门控** | 每帧"纯净纸纹 / 纯墨黑"占比（局部方差 < 26 且 亮度 > 186 或 < 26）**≥ 35%**，每 1 秒采一帧 |
| T19 | **文字可读性门控** | 每个文字包围盒内 p95−p5 ≥ 55；外扩 20px 环带的 Sobel 边缘密度 **≤ 0.42** |
| T20 | **转场连续性门控** | 8 个交接窗口各采 5 帧：无近黑/近白空帧；相邻帧平均绝对差 ≤ 62；直方图相关 ≥ 0.30 |
| T21 | **灰雾污染门控** | 任一关键帧的中灰占比（58 < L < 168）**≤ 62%** |
| T22 | **V4 审片大图** | 自动生成 output/v4_release/v4_highlights_grid.png（9 高潮 + 8 转场，6×3） |

### 这五道门控在 V4 的开发中**真的拦下过东西**

| 门控判死的东西 | 当时的数值 | 触发的重写 |
|---|---|---|
| s03「铆钉铜门」满屏金属阵列 | 留白率 **0.7%** | 重写为「界画铜门」：中央 62% 宽，四周纯黑深渊 |
| s03「CG 银杯」高光圆柱 | 留白率 **0.7%** | 重写为「水墨微距」：倾覆金樽（墨胎 + 金口）+ 朱砂酒渍漫开，纸面占 65% |
| s02 群山一上来就糊满全帧 | 留白率 **14%** | 加「天头留白」：群山自纸中升起（0–4.3s），山脚白云提到纸色 |
| s03「两极静帧」的雪原是一片中灰 | 留白率 **27.5%** | 雪原压到真正的墨黑，只在地平线留一道雪光 |
| 文字压在雨丝 / 水纹上 | 对比度 **12**（s02 落款） | 小字加深、包围盒收紧，并给 `inkText` 加局部消光护罩 |
| 转场硬切 | 单步承担 **62%** 的画面变化 | 交叠窗口内只留 0.36s 溶解，其余交给 Whip Pan / Zoom-through |

> 这正是 V3 的 17 项探针测不出、而观众一眼就能看出的东西。
> **门控不是为了让自己过得舒服，而是为了让自己不得不过不去。**

## 8. 还有哪些没做完


1. **旁白**。V4 仍然是零人声。若要做"抖音爆款"版本，应当再用 edge-tts 做一版男声旁白
   （V1/V2 已有全套流程），与现代文译注字幕并行 —— 这是 V5 最该动的一刀。
2. **s03 的暴风雪旷野** 仍偏灰（_wasteSky 的中灰带太宽），可再压 15% 的中灰。
3. **s08 的青铜重简** 目前是渐变柱体，还不是界画 / 碑拓语言，下一版应换成毛笔语言。
4. engine/kinetic.js 里的旧基元（textIn / verticalIn / particleText）已基本无人调用，
   可以删掉以减少认知负担。
