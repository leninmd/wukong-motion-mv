## 二、对调研文档的勘误

1. **出三峡年份**
   文档：「766年出三峡到江陵」。实际：**768 年正月**出峡（《大历三年春白帝城放船出瞿塘峡》）。
   本片不把「出峡」放在 766 年。

2. **草堂建成年**
   文档：「761年三月于浣花溪畔建草堂」。实际：**759 年十二月**抵成都，**760 年春**草堂落成；
   761 年秋才是「茅屋为秋风所破」。本片按 760 年建、761 年破。

3. **陷贼时间**
   文档把「746–756 陷贼」放在同一格。实际：756 年 7 月被俘，757 年 4 月逃出。本片 HUD 用
   「长安·七五六·陷贼」。

4. **《登高》系年**
   文档表头写「夔州·七六六·登高」。实际作于 **767 年重阳**。本片 HUD 用「夔州·七六六」出场、
   「七六七·望岳（回溯）」收束，登高诗行放在 766–767 的长江段落里。

5. **累计里程**
   文档给出的 3,410 km 与其自列的路线不自洽。按今地图直线距离 ×1.3 的陆路/水路折算，
   巩县→兖州→长安→鄜州→长安→华州→秦州→同谷→成都→夔州→江陵→岳阳→潭州→衡州→耒阳→潭州
   约 **4,739 km**。本片 HUD 与旁白统一用「4,739 km／四千七百公里」，并在文档中标注为**估算值**。

6. **HUD 起点**
   文档示例「兖州·七三六·壮游 0 km」与出生地矛盾。本片从「巩县·七一二·出生 0 km」起算。

7. **存诗数量**
   「一千四百余首」为现存口径（《杜诗详注》收诗一千四百余首），非创作总数（散佚甚多）。
   旁白用「留下一千四百多首诗」，成立。

8. **「诗圣」**
   该称号明清以后才流行，唐代无此称谓。本片只在落版处作为**印章符号**使用，不作为史实陈述。

9. **家庭人数**
   「一家五口」是常见通俗说法（杜甫有宗文、宗武等子女），史料对其子女数与卒年仍有争议。
   本片旁白改用「一家人」，避免坐实。

10. **绝笔诗句**
    「战血流依旧，军声动至今」出自《风疾舟中伏枕书怀三十六韵》，是学界公认的绝笔，可用。

## 三、工程参数勘误（文档 vs 本实现）

| 文档主张 | 本实现 |
|---|---|
| 1920×1080 / **60fps** | 1920×1080 / **30fps**（与参考片同帧率，且渲染成本减半） |
| Remotion + React | 纯 HTML5 Canvas + `window.seek(t)` + Playwright（零授权、零 node 依赖） |
| 用 ffmpeg 抽帧后由模型"看图"质检 | 主质检用逐秒抽帧拼图 + 像素/几何数值探针（本仓库 `output/qa/`） |
| Matter.js 刚体预烘焙 | 用解析式自由落体 + 回弹近似（同样确定性，无外部依赖） |
| Three.js 3D 点云 | 手写透视投影 + 点云（无 WebGL 依赖，逐帧确定性更好控制） |
| qa-gate 的 15%/50%/85% 三点抽样 | 改为逐秒全片抽帧 + 关键帧人工目检，覆盖面更大 |
