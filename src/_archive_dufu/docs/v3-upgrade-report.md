## 一、文本准绳：把"杜撰"清零

V3 的第一条不是画面，是**字**。全片屏幕上出现的每一个字，都能在传世文献里逐字找到。为此我核对了四处一手文献：

| 文献 | 核对到的原文 | 用在哪 |
|---|---|---|
| 《旧唐书·杜甫传》 | 「杜甫，字子美，本襄阳人，后徙河南巩县。」「儿女饿殍者数人。」 | S01 主文、S07 碑文 |
| 《新唐书·杜甫传》 | 「甫，字子美，少贫不自振，客吴越、齐赵间。」「自鄜州羸服欲奔行在，为贼所得。」「数尝寇乱，挺节无所污。」「情不忘君，人怜其忠云。」 | S02 落款、S07 判词、S09 史笔 |
| 元稹《唐故工部员外郎杜君墓系铭》 | 「则诗人以来，未有如子美者。」 | S08 右注 |
| 韩愈《调张籍》 | 「李杜文章在，光焰万丈长。」 | S08 定论 |
| 杜甫原诗 7 首 | 望岳 / 自京赴奉先 / 茅屋 / 登高 / 旅夜书怀 / 风疾舟中 | S02–S09 |

### ⚠️ 对 V3 脚本初稿的 4 处勘误（都在 `docs/v3-引文考据.md` 里）

1. **S01 出处标错**：「杜甫，字子美，本襄阳人，后徙河南巩。」出自**《旧唐书》**而非《新唐书》，且原文是「后徙河南**巩县**」。
   → 改标《旧唐书》，补「县」字。
2. **「穷居草野，身蒙垢辱」两唐书均无此句**（现代仿古）。
   → 换《新唐书》真实判词：「**数尝寇乱，挺节无所污。**」（更有力：乱世里没脏过手）
3. **「未尝一日忘天下」不是《新唐书》赞语**（该语见于他书评虞翻、孔子，与杜甫无关）。
   → 换传末原文：「**情不忘君，人怜其忠云。**」
4. **「天宝之前 · 齐赵壮游」是现代断代说法**。
   → 换《新唐书》原文「**客吴越、齐赵间**」+ 编年「开元二十四年」。

另外，初稿 S07 碑面五条（「困守长安十年」「陷贼身蒙垢辱」「同谷采橡充饥」「幼子死于饥馁」「老病漂泊孤舟」）也都是现代概括，
**全部换成史传原句**：`举进士不中第，困长安。`／`自鄜州羸服欲奔行在，为贼所得。`／`寓居成州同谷县，自负薪采稆。`／`儿女饿殍者数人。`／`扁舟下荆、楚间，竟以寓卒。`
——冷、准、狠，且一个字都不用我编。

## 二、零旁白：把声音交给环境与留白

V2 的男声旁白全部删除。V3 音轨只有：低频持续音、风、雪、雨、江涛、铜门、青铜钟、古磬、尺八长音、鸟鸣。
情绪靠**动静对比**扛：

| 段落 | 声音设计 |
|---|---|
| S01 0–10 | 近乎静默；2.0s 一声金铁坠纸 + 古磬 |
| S02 10–24 | 高山风啸 + 排箫单音 |
| S03 24–38 | 笙歌骤停 → 铜门闭锁重击 → 暴风雪 |
| S04 38–54 | 暴雨 → **41.9–43.15 秒两秒真空** → 洪钟古磬 |
| S05 54–68 | 40Hz 江涛 + 枯叶裂空 |
| S06 68–82 | 几乎无声，水拍 + 鸟鸣 + 尺八 |
| S07 82–98 | 五记巨石坠地 → **87.6–98.0 七秒绝对静默** |
| S08 98–110 | 地火低鸣 → 青铜大钟 |
| S09 110–120 | 风雪渐微 + 远寺钟，余音收在 120s |

两段静默是硬门（`blackout()` 直接写 0），实测 88–98s RMS = 0.0000。

## 三、八层渲染管线

`engine/v3/eight-layer.js`：L1 麻纸基质 → L2 环境资产 → L3 体积光 → L4 物理/特效 → L5 排版 → L6 气溶胶 → L7 调色 → L8 颗粒与暗角。

新增四个引擎模块：

| 模块 | 解决什么 | 关键实现 |
|---|---|---|
| `paper-fluid.js` | 宣纸不再是"一张图" | fBm 分形凹凸 + 横纵纤维 + 纸帘纹 + 杂质；**墨渗字**：噪声打孔做飞白，四向微位移叠出毛细毛边 |
| `celestial-lattice.js` | 天上的广厦 | 黄金角螺旋排布 46 座重檐庑殿顶线框（正脊+鸱吻+起翘檐+斗拱），逐座生长 + 檐下光晕 + 体积光柱 |
| `fine-poly-ruins.js` | 断碑不是矩形 | 8~12 顶点**板状**破碎多边形（沿矩形周界取点带崩口），预烘焙物理，落地压掉冗余旋转保证碑文可读，带地面 AO 阴影；另含 160 颗布朗漂移气溶胶 |
| `eight-layer.js` | 告别扁平 | 八层合成 + 黑矛雨 `spearRain` + 体积光 `volumetricLight` + 云海 `cloudBank` |

## 五、实测数据

- 120.0s / 7,200 帧 / 1920×1080 / 60fps / H.264 + AAC

## 六、尚存不足

1. **S02 的"万仞悬崖"仍是小体量**：孤石 + 云海的构图成立，但没有真正的"壁立千仞"纵深（点云尺度不够）。
2. **断碑不是"崩塌堆叠"而是"碑林站立"**：为保证碑文可读，我把落地后的旋转压掉了；代价是少了倒塌的惨烈。若要"堆"，得放弃文字可读性。
3. **没有做 9:16 竖屏版**：引擎与分镜目前按 1920×1080 硬编码坐标系，双端自适应需要先抽一层 layout 抽象（约 40% 额外工作量）。
4. S03 的微距段落（杯/酒/雪下手）是纯矢量拼接，放大看仍是"画的"，不是材质。
