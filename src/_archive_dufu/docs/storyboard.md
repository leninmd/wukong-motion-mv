## 三、视听语法（从原片逆推）

1. **色彩**：宣纸 `#E7DAC2`／徽墨 `#1A1309`／朱砂 `#D8402A`。全片只有这三种颜色 + 夜海的墨绿黑 `#16170F`。
2. **字体**：思源宋体 Heavy（标题/大字）、Noto Serif SC（正文）、霞鹜文楷（诗行/手稿感）、马善政毛笔（未用上，留作备选）、等宽 Courier（数字/年份）。
3. **HUD**：右上角两行——`地点 · 中文纪年 · 事件` + `累计公里`，右对齐、低对比、进场右滑 18px、出场上飘。
4. **五层堆栈**：纸/夜景底 → 程序化资产（活字/茅草/竹/水/点云）→ 排版 → 调色（soft-light 渐变网格）→ 胶片颗粒 + 暗角。
5. **运动**：全部由 `t` 的纯函数驱动；`Ease.outExpo / spring / easeInExpo`，禁止线性；入场 Fade+Rise+Scale+Blur 四属性联动；退场时长约为入场的 40%。
6. **转场**：硬切为主，纸↔夜的交替用 0.25–0.3s 交叉溶解。
